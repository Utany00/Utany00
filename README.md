# Hi, I'm Uta 👋

**AI made building cheap. The expensive part is deciding what deserves to be built.**

I work on the systems underneath product and AI: how companies frame decisions, assign authority, deploy agents, measure outcomes, and stay coherent as execution gets faster.

I have built the version that does not hold, the repaint that looks like a rebuild. That is where I learned to tell the difference. Machine learning in product since 2015: recommendations and personalization at consumer scale, and most recently a customer data platform built to feed agentic systems.

This GitHub is my lab for one question: **what happens to management when machines make execution cheap?** My working answer: judgment, coherence and organizational design become more valuable, not less.

## Current work

**[Question Before the Question](https://github.com/utaknablein/question-before-the-question)** 
Before AI answers a consequential question, check whether it is the right question. A framework and prototype for surfacing hidden assumptions and reframing decisions before execution begins.


**[Product Operating System](https://github.com/utaknablein/product-operating-system)** 
AI makes execution faster. This is the structure I use to keep strategy, priorities, ownership, metrics, and engineering capacity moving as one system.


**[Board Devil's Advocate](https://github.com/utaknablein/board-devils-advocate)** 
An independent AI challenger that pressure-tests a board proposal before the meeting.


**[Agent Workflows](https://github.com/utaknablein/agent-workflows)** 
Patterns for delegating real leadership work to agents: triggers, permissions, human checkpoints, and measurement.


**[ENGINE](https://github.com/utaknablein/engine-diagnostic)** 
A diagnostic for whether an organization can actually carry AI transformation rather than simply add AI tools. [Take the diagnostic](https://utaknablein.github.io/engine-diagnostic/).


**The thread through all of them:**

Question → Judgment → Decision → Execution → Outcome → Learning

The faster machines make execution, the more important that loop becomes.
