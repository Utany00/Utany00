# Hi, I am Uta 👋

**AI made building cheap. The expensive part is deciding what deserves to be built.**

I build the operating systems that help companies turn strategy into growth: how decisions get made, how teams align, how technology gets deployed, and how organizations stay coherent as execution gets faster.

This GitHub is my lab for one question:

**What happens to management when machines make execution cheap?**

My working answer: **judgment, coherence, and organizational design become more valuable, not less.**

## Current work

### [Question Before the Question](https://github.com/utaknablein/question-before-the-question)

**AI answers what you ask. This asks whether you are asking the right question in the first place.**

A framework and prototype for surfacing hidden assumptions before they become decisions and execution.


### [Product Operating System](https://github.com/utaknablein/product-operating-system)

A system for keeping **strategy, priorities, decision rights, metrics, and engineering capacity** on one plan as execution gets faster.


### [Board Devil's Advocate](https://github.com/utaknablein/board-devils-advocate)

An independent AI challenger that pressure-tests consequential proposals **before the decision is made**.


### [Agent Workflows](https://github.com/utaknablein/agent-workflows)

Patterns for delegating real work to agents: **triggers, permissions, human checkpoints, escalation, and measurement**.


### [ENGINE](https://github.com/utaknablein/engine-diagnostic)

A diagnostic for whether an organization can actually carry AI transformation rather than simply add AI tools.
